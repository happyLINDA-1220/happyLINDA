# 金灶鍋貼｜線上點餐串接 Google Sheets

網站按下「確認送出訂單」後，訂單會送到 Google Apps Script（GAS），由它寫進 Google 試算表並寄 Email 通知店家。

## 試算表會有哪些工作表

| 工作表 | 用途 |
| --- | --- |
| 訂單 | 一張訂單一列。「狀態」欄可下拉選擇：新訂單／製作中／可取餐／已完成／已取消，會自動上色 |
| 訂單明細 | 每個品項一列，方便統計各品項銷量 |
| 菜單 | **價格以這裡為準**。改價格、取消勾選「上架」即可停售，不必改網站程式 |
| 每日營收 | 自動統計每天的訂單數、份數、營收（不含已取消） |

## 安裝步驟（第一次）

1. 開一個新的 Google 試算表（或用你已經建好、目前網址對應的那個）。
2. 上方選單「擴充功能」→「Apps Script」。
3. 把 `Code.gs` 的內容**整份貼上**，取代原本的程式碼，按儲存。
4. （可選）修改最上面 `CONFIG` 的 `NOTIFY_EMAIL`，填入要收新訂單通知的信箱；留空會寄給你自己的 Google 帳號。
5. 上方函式選單選 `setup`，按「執行」。第一次會要求授權，依畫面允許即可。執行完試算表會出現上面四個工作表。
6. 部署成網頁應用程式：
   - **第一次部署**：右上「部署」→「新增部署作業」→ 類型選「網頁應用程式」→ 執行身分「我」、存取權「所有人」→ 部署，複製網址貼到 `index.html` 的 `ORDER_API_URL`。
   - **已經有部署網址（要保留同一個網址）**：「部署」→「管理部署作業」→ 點鉛筆圖示 → 版本選「新版本」→ 部署。網址不變，網站不用改。

> 每次修改 `Code.gs` 後，都要用「管理部署作業 → 新版本」重新部署，網站才會用到新程式。

## 測試

- 用瀏覽器直接打開部署網址，看到 `{"ok":true,...}` 代表 API 正常。
- 到網站加幾樣餐點、填資料送出，試算表「訂單」應該會多一列，信箱也會收到通知。

## 安全機制

- 金額由後端依「菜單」重新計算，網頁上的價格被改也沒用。
- 同一支電話 30 秒內只能送一張單，避免連點重複下單。
- 隱藏欄位擋掉自動填表的機器人。
- 輸入內容若以 `=`、`+`、`-`、`@` 開頭，會被當成純文字，不會在試算表裡變成公式。

## 查詢訂單狀態（之後要做查詢頁可用）

`GET 部署網址?action=status&orderId=JZ-20261127-001&phone=0912345678`
→ 回傳 `{ ok, orderId, status, orderType, total }`，電話不符會回「查無此訂單」。
